# Objective

Turn a topic into a visual promise that survives mute playback and has a
clear information-bearing hero frame.

The brief must make the core question, viewer promise, visual motif, hero
moment, ending beat, and rejected alternatives explicit. Creative decisions
are ranked by retention and visual comprehension before production cost.

# Inputs

Research pack, reference deconstruction, channel brand language, and episode
manifest.

# Outputs

`creative_brief.md`, updated creative fields in `episode.yaml`, and explicit
deterministic-vs-AI production boundaries.

# Required Workflow

1. State the viewer promise and first anomaly time.
2. Define emotion, escalation, payoff, and loop.
3. Name the hero shot and why deleting it hurts.
4. Reject decorative shots that only illustrate narration.
5. Record decisions in the manifest and brief.
6. Keep one primary promise and one recurring motif; do not let research
   breadth turn into multiple competing openings.
7. Mark each planned peak as HERO, STORY, or CONNECTOR so the storyboard and
   generation plan inherit a clear visual hierarchy.

# Quality Gate

The first 1.5 seconds contain an event, the mute read is understandable, and
at least three visual peaks are named. The hero shot must carry information,
not merely decorate the narration, and the ending must either pay off the
promise or create a credible loop.

# Failure Conditions

No hook, no measurable visual thesis, no hero shot, or unsupported factual
claim presented as certainty.

# Tools

Manifest loader, reference pattern YAML, Beads.

# Forbidden Patterns

Do not write research, build Blender scenes, or approve a final upload.

# Handoff

Pass the brief and rejection notes to `short-script-editor` and `shot-designer`.
