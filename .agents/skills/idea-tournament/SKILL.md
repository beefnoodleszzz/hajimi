---
name: idea-tournament
description: Compare story candidates through pairwise reasoning and compose stronger hybrid angles.
---

# Objective

Turn a discovery set into a comparative decision. Remove ordinary ideas,
mutate the strongest angles, and preserve the option to combine hook, motif,
escalation, and ending from different candidates.

This stage consumes the current discovery artifact and context pack. It must
not read a fixed winner, Python rank table, or previous episode answer.

# Required Workflow

Generate 15–30 candidates when discovery is live, shortlist 5–8, create 10–15
angle variants, then record pairwise reasoning across hook, visual clarity,
novelty, escalation, emotion, defensibility, generation fit, hero potential,
and loop potential.

Every comparison includes a counterargument. The output must contain
`selected_direction` with `hook_from`, `visual_motif_from`, `escalation_from`,
`payoff_from`, and `ending_from`, so a composite winner is a first-class result.

# Quality Gate

The output must explain why A beats B, not only assign scores. The winner may
be a composite candidate rather than one original topic.
