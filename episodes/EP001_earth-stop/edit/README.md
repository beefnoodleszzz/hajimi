# Resolve Edit Handoff

DaVinci Resolve 21.1 is the creative editor of record. Import the approved
shot renders in manifest order, then perform trimming, J/L cuts, pacing,
speed/beat alignment, Fusion graphics, Fairlight mix, and delivery.

`resolve_sync_manifest.json` is generated by:

```bash
uv run hajimi resolve sync EP001_earth-stop
```

The current local render is an animatic proof, not a claim that Resolve has
been mutated or that a final production timeline exists.
